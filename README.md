
# Espacios con Estilo

## Descripción
Espacios con Estilo es una página web sobre diseño de interiores y decoración. Su objetivo es mostrar diferentes estilos y ayudar a las personas a organizar sus ideas para transformar sus espacios.

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript

## Funciones
- Navegación entre cuatro secciones.
- Información sobre estilos de decoración.
- Cuestionario para recomendar un estilo.
- Calculadora de presupuestos en bolivianos.
- Lista de estilos favoritos.
- Formulario de contacto.
